Experiment Procedure

  1. Set the quantum number n and the box length L.
  2. Choose the particle mass in units of the electron mass.
  3. Select wavefunction, probability density or potential-well view.
  4. Run the simulation and observe how the spatial state changes.
  5. Compare the calculated energy with the theoretical relation and record the observation.
ψₙ(x) = √(2/L) sin(nπx/L)     Eₙ = n²h²/(8mL²)

For the infinite well, ψ = 0 at x = 0 and x = L. Increasing n raises the energy quadratically and increases the number of nodes.
